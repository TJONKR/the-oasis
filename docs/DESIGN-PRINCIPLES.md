# The Oasis — Design Principles

## 🌍 The Reality Test
Every feature, every system, every change — ask:

> **"Zou dit in de echte wereld ook zo werken?"**

If not, fix it. The goal is not a game. The goal is a world.

## Two Guiding Questions
1. **Natuur**: "Why doesn't this world behave like real nature?"
2. **Beschaving**: "Why don't these agents behave like real humans?"

## Core Rules

### Everything Must Emerge
- No bounty boards, no quests, no scripted events
- We build intelligence (agent AI) and physics (world systems)
- Agents figure out the rest themselves
- If agents don't do something, it means they're not smart enough yet — fix the intelligence, not the outcome

### No Game Objects
- ❌ Bounty boards, quest logs, achievement popups
- ✅ Natural consequences, emergent behavior, physics-based systems
- The difference: a bounty board TELLS agents what to do. Hunger + surplus detection + relationship memory LETS agents figure out trading on their own.

### World Master = Diagnosis, Not Direction
- The World Master LLM observes and diagnoses what's missing
- It does NOT control agents or script events
- Its output is a roadmap for US to improve intelligence/physics
- Agents can "pray" to receive insights (future feature)

### Two Layers of Intelligence
1. **Agent AI** — individual brains with personality, needs, memory, relationships
2. **World Intelligence** — diagnoses civilization gaps, identifies what's preventing emergence

### The Civilization Feedback Loop
```
World Master diagnoses gaps → we read them →
we improve agent/world intelligence →
World Master diagnoses again → fewer gaps →
civilization emerges naturally
```

## Known Reality Gaps
Things that don't match how the real world works:

### Nature
- [ ] Berry respawn is timer-based (should: seed → grow → fruit → harvest → regrow)
- [ ] No real seasons
- [ ] Water doesn't flow based on elevation
- [ ] Dead animals disappear instead of decomposing → feeding soil
- [ ] Fire doesn't leave fertile ash
- [ ] No erosion from rain/wind
- [ ] No nutrient cycles (organic matter → soil → plants → animals)
- [ ] Temperature lacks thermal mass and shade
- [ ] No real day/night cycle effects (sleep, visibility)

### Civilization
- [ ] Agents don't form settlements
- [ ] No specialization (everyone is a generalist)
- [ ] No collective memory (knowledge dies with agents)
- [ ] No permanent structures
- [ ] No agriculture
- [ ] No territorial behavior
- [ ] No cultural transmission
